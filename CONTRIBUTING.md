# Contributing

1. Create a focused branch from `main`.
2. Install backend requirements and frontend dependencies.
3. Run `python -m pytest tests/ -v` and `cd frontend; npm run build`.
4. Keep evaluation behavior grounded in observable evidence and preserve the offline fallback.
5. Open a pull request describing the user-facing and test changes.

Do not commit `.env` files, API keys, generated databases, or build output.
